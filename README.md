# 🎸 Telegram CMS Bot для Преподавателя Музыки

Информационный чат-бот с полноценной встроенной панелью администратора (CMS), разработанный для автоматизации маркетинга, презентации услуг и лидогенерации для частного преподавателя музыки (гитара, вокал, клавишные).

**🔗 Ссылка на демонстрационную версию бота:** [@Demo_Music_Teacher_bot](https://t.me//Demo_Music_Teacher_bot) *(работает в режиме Staging)*

---

## 🚀 Ключевой функционал

### 👤 Для пользователей (Учеников):
* **Интерактивное меню:** Удобная навигация по разделам «О преподавателе», «Цены и абонементы» и подробному FAQ.
* **Лидогенерация:** Прямая интеграция с личным профилем преподавателя для оперативной записи на пробный урок.
* **Мультимедиа:** Отображение актуальных медиа-материалов (главное фото профиля) и динамическое обновление описаний.

### 👑 Для администраторов (Преподавателя):
* **Встроенная CMS (No-Code изменение контента):** Возможность редактировать любые тексты меню, блоки цен и разделы FAQ прямо через чат Telegram в реальном времени, без изменения исходного кода программы.
* **Динамическая замена медиа:** Команда `/edit_photo` позволяет обновить главное фото профиля на лету, просто отправив новую фотографию боту.
* **Отказоустойчивость (Reset):** Наличие команд моментального сброса любого текстового блока к первоначальным эталонным настройкам на случай ошибок ввода.

## 🛠 Архитектурные особенности и Стек технологий

Проект прошел путь от монолитного MVP до зрелой продакшн-архитектуры:
* **Язык разработки:** `Python 3.11+`
* **Фреймворк:** `Aiogram 3` (асинхронная архитектура, использование `Router` для изоляции модулей и масштабируемости).
* **Управление состояниями (FSM):** Потокобезопасное переключение контекстов администрирования через `FSMContext` (исключает конфликты при одновременной работе нескольких админов).
* **Авторизация:** Безопасность административных команд вынесена в кастомный переиспользуемый фильтр доступа (`BaseFilter`).
* **Хранение данных (Data Persistence):** Легковесная файловая база данных на базе JSON. Реализована динамическая запись изменений на диск с обработкой исключений (`try...except`). Данные гарантированно сохраняются при перезапуске сервера/контейнера.
* **Безопасность:** Конфиденциальные данные и API-токены полностью изолированы от кода и управляются через переменные окружения.

## 📦 Инструкция по локальному развертыванию

### Способ 1. Запуск через Docker (Рекомендуемый)

Убедитесь, что у вас установлены Docker и Docker Compose.

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com//RomanSazonovPNZ/music-teacher-cms-bot
   cd music-teacher-cms-bot
   ```
2. Создайте файл конфигурации окружения `.env` (или `.env.test`) в корне проекта:
   ```text
   TEACHER_BOT_TOKEN=1234567890:ABCdefGhIJKlmNoPQRsTUVwxyZ
   ```
3. Соберите Docker-образ:
   ```bash
   docker build -t music_teacher_img .
   ```
4. Запустите контейнер с передачей файла окружения:
   ```bash
   docker run -d --name music_teacher_bot --restart unless-stopped --env-file .env music_teacher_img
   ```

### Способ 2. Классический запуск в виртуальном окружении

1. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv venv
   source venv/bin/activate  # Для Linux/macOS
   # venv\Scripts\activate   # Для Windows
   ```
2. Установите зависимости:
   ```bash
   pip install -r requirements.txt
   ```
3. Экспортируйте токен бота в переменные окружения вашей системы и запустите точку входа:
   ```bash
   export TEACHER_BOT_TOKEN="ваш_токен"
   python main.py
   ```

## 📁 Структура проекта

```text
├── config.py          # Глобальная конфигурация, ID администраторов, эталонные тексты
├── storage.py         # Модуль персистентности (чтение/запись JSON, сброс к эталонам)
├── filters.py         # Кастомные фильтры Aiogram (проверка прав администратора)
├── keyboards.py       # Менеджер генерации inline-клавиатур и меню
├── handlers.py        # Обработчики бизнес-логики и команд (пользовательские/админские)
├── main.py            # Точка входа, инициализация бота и регистрация роутеров
├── Dockerfile         # Инструкция сборки легковесного контейнера на базе python-slim
├── .dockerignore      # Исключение системного мусора (__pycache__, локальных баз) из сборки
└── requirements.txt   # Зависимости проекта
```
